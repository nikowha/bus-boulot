# bus-boulot

Webapp perso des prochains bus Metlink (Wellington) pour deux arrêts :

- **6080 - WETA** (Miramar Avenue at Tauhinu Road)
- **7096 - MAISON** (Ahuriri Street at Tukanae Street)

Fonctions : 4 prochains bus par arrêt, filtre par ligne, heure prévue · retard/avance · nouvelle heure,
carte du bus en temps réel (suivi du tracé), rafraîchissement toutes les 5 s.

## Utilisation

Ouvrir la page, coller sa clé API Metlink (gratuite sur [opendata.metlink.org.nz](https://opendata.metlink.org.nz/))
dans « Clé API Metlink ». La clé reste dans le navigateur, elle n'est jamais dans ce dépôt.

Sur iPhone : ouvrir la page dans Safari → Partager → « Sur l'écran d'accueil ».
